Mendy

A simple Markdown editor for macOS. Write in plain files, see the result as you type.

Coming soon · macOS 14 or later

Features

Everything you need to write Markdown — and nothing you don't.

Your folders, your files

Open any folder and edit plain .md files. No database, no import, no lock-in.

Live preview

See the formatted result side by side as you type, with tables, task lists, code, and images.

Type / for syntax

Don't remember the Markdown for a table? Type / and pick it from a list.

Images made easy

Drag and drop images or paste a screenshot. Mendy saves the file and writes the link for you.

Styled editing

Headings, bold text, and code blocks are formatted right in the editor, so it's easy to read.

Export & print

Export to HTML or PDF, or print — with clean, readable formatting.

Why “Mendy”?

101Md

Mendy is named after mendelevium, element 101 on the periodic table. Its symbol is Md — the same as the .md extension of Markdown files.
