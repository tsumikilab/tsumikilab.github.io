# tsumikilab.github.io

Source of the Tsumiki Lab website, **https://tsumikilab.app**, served by GitHub Pages.

Plain HTML and CSS, with no build step:

- `index.html` — home page
- `mendy/index.html` — Mendy page
- `404.html` — page-not-found
- `assets/` — stylesheet, logo, icons and social preview image
- `CNAME` — the custom domain

The logo and icon images are generated by `make-avatar.swift` in the Tsumiki Lab brand folder
(`swift make-avatar.swift <folder> site`).
